# Cannabis Process Map — preview

Public preview build of the Cannabis Manufacturing AS-IS process map viewer.
Source, generators and specification are kept private.

**Live:** https://abdullahelsadek21-luxsh.github.io/cannabis-process-map-preview/

Two views in one self-contained page:

- **Phase overview** — eight phases, six teams, two release gates, and a team × phase matrix
- **Detailed map** — all 33 steps as vertical swimlanes, top to bottom

No build step, no backend.
